## Mục tiêu
Thực hiện 3 bài Lab JavaScript của học phần Phát triển ứng dụng TMĐT:
- **Lab 08 – JavaScript 1: Language Foundations**: cú pháp, biến, mảng, hàm, đối tượng, Console.
- **Lab 09 – JavaScript 2: DOM and Events**: thao tác DOM, xử lý sự kiện, form, gỡ lỗi.
- **Lab 10 – JavaScript 3: jQuery**: selectors, sự kiện, hiệu ứng, GET request và jqXHR.
